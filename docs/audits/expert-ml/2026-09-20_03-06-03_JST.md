## 二、最有价值的机制：RSI回升不一定是新增价格走强

设 d_t=C_t-C_(t-1)，g_t=max(d_t,0)，l_t=max(-d_t,0)。令U、D是t-1时刻过去n=14个价差的上涨量、下跌量之和；均值中的1/n相消，所以：

    F(U,D)=100U/(U+D)

全平U=D=0时约定50；真正缺失仍为NaN。新进入窗口的是(g_t,l_t)，离开窗口的是(g_(t-n),l_(t-n))。

构造四个状态：

    R00 = F(U,D)
    R10 = F(U+g_t, D+l_t)
    R01 = F(U-g_(t-n), D-l_(t-n))
    R11 = F(U+g_t-g_(t-n), D+l_t-l_(t-n))

只按“先加后删”会把交互全部分给某一边。这里对两种顺序取平均：

    N_t = 0.5 * [(R10-R00) + (R11-R01)]
    E_t = 0.5 * [(R01-R00) + (R11-R10)]

因此严格有：

    RSI_t - RSI_(t-1) = N_t + E_t

N是新增价差贡献，E是滚出贡献，单位都是RSI点。这是一个两操作的对称分摊恒等式，不是统计因果识别、真实资金流或机构行为估计。实现用共同n-1个价差求和构造四状态，避免大数相减产生负微小量。

**实际反例**：前14个价差为[-4,+0.1,-0.1,…,+0.1]，即一笔-4和13笔小幅交替变化；当天新增-0.05。

| 量 | 本轮执行值 |
|---|---:|
| 前日SMA-RSI14 | 13.207547 |
| 当日SMA-RSI14 | 51.851852 |
| RSI变化 | +38.644305 |
| 新增价差贡献N | -1.058869 |
| 旧价差滚出贡献E | +39.703173 |

价格当天仍下跌，RSI却上穿50。RSI公式没算错；把这次上涨全部解读成“新动量增强”才不成立。旧跌幅退出也可能有预测价值，所以E保留为诊断，不先验删除它。

## 三、主因子定义及输入schema

取h=3，N3_t=sum(N_(t-2:t))，E3_t=sum(E_(t-2:t))，ΔR3_t=RSI_t-RSI_(t-3)。仍有ΔR3=N3+E3。

价格承接使用两个不重叠、截至t已知的Low窗口：

    Lpre_t = min(Low_(t-24), …, Low_(t-5))   # 前20日
    Lnow_t = min(Low_(t-4), …, Low_t)        # 近5日
    B_t = max(0, log(Lpre_t/Lnow_t))
    H_t = exp(-B_t/0.03)
    RER_t = max(0, tanh(N3_t/5)) * H_t

5的单位是RSI点；0.03是log价格破坏尺度。都是首轮预注册起点，不是调出来的最优数值。这不是H504的20%风险标签，也不是新的止损/成交规则。

RER只提供一个有界“新增恢复且价格结构未严重破坏”的表达。它不要求RSI<30或RSI<70。持续上涨时RSI=100、N3=0、RER=0，表示没有新增的恢复变化，不表示应卖出，也不屏蔽其他趋势信号。

建议核心模型列：RSI14、ΔR3、N3、B、RER、相对绝对价格路径幅度A14；E3用于解释即可，因为已有ΔR3和N3时E3严格线性冗余。NaN mask、flat标志和数据版本独立记录，不把数值0等同缺失。

    A14 = sum(abs(d_(t-13:t))) / C_(t-14)

对于非平盘窗口：RSI=50*[1+(C_t-C_(t-14))/sum(abs(d))]。因此RSI本来就是净价格变化与路径总变动的比例摘要。加入RSI或本因子不带来新的外部行情信息，可能带来有限容量模型更好利用历史数据的表达；必须加等历史长度原始价差对照，不把可代数重构的特征包装为新的信息源。

价格不需要归一为统一金额；正比例缩放不改变因子。E、Close和Low仍必须使用同一经过验证的价格基准。缺失日不得删去压缩为连续bar。候选模块在独立日历上补空行，不填价格；跨缺口的RSI与承接窗口为NaN，新的完整窗口满足后才恢复。Wilder的递推不具有相同“硬滚出”结构，不能直接套本分解。

## 七、固定的同条件实股对照矩阵

B为非KDJ/非RSI的共同价量、长期位置、市场特征，并把本次价格支撑破坏B_t与A14放在所有组，避免把增加Low信息误归因为RSI。K为全部KDJ及其派生。R为SMA-RSI14和三日变化。所有依赖RSI/KDJ的旧专家score必须从“去RSI/去KDJ”组一并去除。

| 组 | 输入 | 对照解释 |
|---|---|---|
| A | B | 不用振荡指标 |
| B | B+K | KDJ增量 |
| C | B+R | RSI状态增量 |
| D | B+K+R | KDJ已存在时的RSI增量，D对B |
| E | D+N3 | 新增/滚出分解的表达增量，E对D |
| F | E+RER | 有界恢复与承接交互，F对E |
| G（严格控制） | B+K+等历史长度原始价差统计 | 历史覆盖/原始信息控制 |
| H | G+R+N3+RER | 比较表示而非新外部信息 |

E3与ΔR3/N3完全冗余，默认不重复加权。补充分数退化控制（同分组阈值）、噪声列控制、按时间块/股票簇的负控制，失败结果全部保留。
