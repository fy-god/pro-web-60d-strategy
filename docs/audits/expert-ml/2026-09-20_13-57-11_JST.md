## 2. 新增确认问题

### EML-P1-TEST-COOLDOWN-FIXTURE-COUPLING

- 级别：P1（测试合同错误）；底层 `EML-P0-COOLDOWN-GRID` 仍为 P0。
- 状态：**CONFIRMED**。
- 文件／函数：`tests/test_engine.py::test_dedupe_cooldown_boundary_is_inclusive`；`src/labels.py::dedupe_signals`。

当前生产实现：

```python
session_index = {d: i for i, d in enumerate(sorted(out["date"].unique()))}
positions = out["date"].map(session_index).to_numpy()
```

这里的 `out` 是**signal frame**，不是独立 market calendar。

更关键的是，当前测试自己的注释明确承认这一点，并为了让目标股票的两次信号相距“60 sessions”，主动在中间每个日期放一条 **filler stock** 信号：

```python
# observed-date grid is dense
for d in dates[:second_offset]:
    rows.append({"code": "000002", "date": d, ...})
```

这不是单纯“缺少一个测试”。它把错误依赖写进了 fixture：目标股票 A 的 cooldown 结果会由无关股票 B 是否在中间发信号决定。

**无需运行即可从当前代码得到精确反例**：

- A 只有 `day0`、`day60` 两条信号，signal-frame unique dates 只有 `[day0, day60]`，positions=`[0,1]`，cooldown=60 → 第二条被压掉；
- 加入 B 在 `day0..day59` 的 filler 信号后，unique dates 变成 61 个，A positions=`[0,60]` → 第二条被保留。

即：

```text
A自己的信号完全不变
只改变B是否发中间信号
=> A的发布账本发生变化
```

这违反“cooldown 按独立 market session 计算”的主合同。

**修复要求**：`dedupe_signals` 不再从 signal frame 重建 session clock；改为显式接收 `market_session_id` 或独立 `market_calendar`。测试必须新增不变性断言：加入／删除无关股票信号，不得改变 A 的 kept signal IDs。

**回归测试**：见 §4.1 `T-CD-IND-01`。
