## 6. 【环境陷阱 · 已实证】`run_fixup.task.xml` 是 UTF-16

`scripts/run_fixup.task.xml` 原始字节以 `b'\xff\xfe<\x00'` 开头。**按 utf-8 解码直接抛 `UnicodeDecodeError`**；按 utf-16 解码得到 `PT2H30M` 与 `PT4H`。`scripts/register_fixup_task.ps1:96` 亦为 `$timeLimit = "PT2H30M"`。

⇒ 任何以 utf-8 读该文件并搜 `PT2H30M` 的探针会得到**假阴性**（不是"值不对"，而是**整个文件读不出来**）。**记录为环境陷阱，供后续轮次避坑。**

相关量（供参考，本轮未主张其为新缺陷）：`scripts/run_fixup.py:23` `AGENT_TIMEOUT_SECONDS = 13200`，而注册任务给 **9000 s**，差 **4200 s**；`:162` `return 0 if rc==0 else 1`，`target_met` 在该文件中出现 **0** 次（阳性对照 `AGENT_TIMEOUT_SECONDS` 出现 **1** 次）。
