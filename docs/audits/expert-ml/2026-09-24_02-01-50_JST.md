## 4. 对 50% 目标的研究判断：当前最值得花三小时的是数据分层与 hard-negative，而不是继续堆模型

结合以上三个仓库实证，下一次用户本机真实 session 应按下面顺序消耗有效时间。

### A. 首 30–45 分钟：把 H504 候选总体拆开，而不是直接全量 fit

必须对真实 candidate/outcome ledger 输出至少：

- success / risk / timeout / no-entry / unknown 原始计数；
- 每年、每股、流动性、上市年限、价格位置、长期回撤、KDJ 区间的 base rate；
- candidate family / KDJ 低位路径 / 长期位置分层的正负比；
- `known_at` / `label_end` / price basis / calendar / candidate hash。

目标不是先训练，而是先找出“哪些候选子总体的自然 base rate 已经高于总基率”。如果没有候选层面的富集，靠下游分类器从 4% 直接跳到 50% 很难稳定。

### B. 中间 90–120 分钟：用同一候选、同一时间折做真正配对训练

优先顺序不再是盲目模型搜索，而是：

1. `T0_clean`: KDJ + 长期位置 + 最小价量基础；
2. `T1_pruned`: T0 + 经历史健康检查后保留的连续 family raw，但**默认不把 cross 全量带入**；
3. `T2_hardneg`: 与 T1 相同特征，增加“历史上最像正例但最终 risk/timeout 的 hard negatives”分层采样诊断；正式指标仍按自然总体、未加权 precision 计算；
4. HGB 与 Logistic / RF / ExtraTrees 做同折基准；只有表格模型确实出现稳定增益后再进 MLP/TCN；
5. 每个 fit 保存全部 dev predictions，禁止只保存阈值后的信号。

### C. 最后 30–45 分钟：专门研究为什么高分样本是假阳性

对最高 score 的 FP 做至少四类切片：

- 先破 0.8E 的 risk；
- 一直没到 4E 的 timeout；
- 高位反弹误判为低位启动；
- 流动性 / 停牌 / 价格基准 / regime 导致的伪相似。

然后只允许基于一个有支持机制做**一次配对修改**，再和原模型同折比较。若时间外 precision 仍 <50%，明确 `TARGET50_NOT_REACHED`，不准用训练内 50% 或很小信号集包装成成功。
