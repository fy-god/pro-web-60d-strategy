### 3.1 反例数值 —— 已确认

当日价差为负（价格仍下跌）而 RSI 上穿 50，机制与报告描述一致：主导项是 −4 滚出窗口。

### 3.2 分解恒等式 —— 数值成立，但**无实证内容**（重要）

- 转移数复现：`50 路径 × 500 观察 = 24,250`，与报告一致。
- 我的最大误差 `4.26e-14`（报告 `3.55e-15`，同一量级，均为 float64 舍入）。

**但该恒等式是构造性重言式**：

```
N + E = ½[(R10−R00) + (R11−R01) + (R01−R00) + (R11−R10)]
      = ½[2·R11 − 2·R00] = R11 − R00
```

`R10` 与 `R01` 项严格相消。这**不使用** `F(U,D)=100U/(U+D)` 的任何性质，对任意 F 都成立。故 24,250 次"检验"**不可能失败**，不能作为已验证性质或任何论据。真正非平凡的是 N/E 的**解释**（新增 vs 滚出），不是恒等式本身。

### 3.3 `RSI = 50·[1 + (C_t − C_(t−n))/Σ|d|]` —— 已确认

代数上：`100U/(U+D) − 50(1 + (U−D)/(U+D)) = 0`。数值上 2,000 个随机非平窗口最大偏差 `1.60e-14`。报告由此推出的"RSI 是净涨跌与路径长度的代数重排、不带来外部信息"**成立**。

### 3.4 "朴素相减会产生负微小量" —— **未复现，降级**

报告第 3 节称实现用共同 `n−1` 项求和构造四状态，"避免大数相减产生负微小量"。我用真实与对抗两种输入测试朴素滚动相减：

| 场景 | 越界（<0 或 >100） | 最小 RSI |
|---|---:|---:|
| 分价位股价、20,000 bars | 0 | +28.57 |
| 2% 波动随机游走、20,000 bars | 0 | +20.87 |
| 单次 1e14 / 1e15 / 1e16 / 1e17 跳变 | **0** | ≥ 0 |

**四种档位全部未复现**（`out_of_range_reachable=False`。注：我首版脚本有一处窗口 off-by-one，已修正后重跑，结论不变）。分解断裂需要 `cumsum|g| / window|d| ≳ 1/ε = 1e12`，而真实数据该比值约 `1e3`，余量约 9 个数量级。

**判定**：该防御性写法是**合理卫生习惯**，但不足以支撑"避免负微小量"这一表述所暗示的现实缺陷。标 `未复现`，**降级为 `待验证风险`**（不列为 `已确认错误`）。

### 3.5 H504 时间可行性算术 —— 已确认

亲手验算报告第五节核心断言（N=887、H=504、warmup=60）：

- 最早训练决策 index `59`，其标签结束 `59+504 = 563`；

这条是本报告最有价值的判断：它**否证**了"用 383 个历史起点随机切分即可造出合法 H504 开发结果"的做法。`887−504=383` 只表示有完整未来窗的**历史起点数**，不等于可切出"先成熟训练、再时间外成熟评价"的折。**据此，"先在本地跑出 H504 实股增量"这一目标在当前 887 会话数据下不可达**，必须先取得更早的授权历史。
