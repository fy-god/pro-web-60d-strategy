### 1.2 `EML-P1-AUX-LABEL-ADMITTED-AS-FEATURE-AT-UNGATED-PATH-001` — `已确认错误`（P1）

**文件/函数/行**
- `aux_tcn.py:87` `tgt=_targets(ps)`；`:89` `f=f.merge(tgt,...)`（把目标帧并入模型帧）
- `aux_tcn.py:18-19` `p['aux_ret1']=np.log(close1/p['close'])`（**未来一日收益**）
- `aux_tcn.py:101` `y_cls=(f['aux_ret1'].to_numpy(float)>0).astype('float32')`（**分类标签**）
- `aux_tcn.py:94` 同一列可被选为**特征**
- `feature_spec.py` 的 `_forbidden('aux_ret1')` = **False**（`aux_` 不在任何前缀表里）

**触发条件/反例（我本人实测，两路独立）**

| 测量 | 结果 |
|---|---|
| M1 `_targets(ps)` 真实输出列 | `['code','date','market_session_id','aux_ret1','aux_rv5']` |
| M1 merge 后 `aux_ret1` 是否在模型帧 `f` 里 | **True** |
| M1 以 `:94` 同式选择 `["ret5","aux_ret1"]` | **成功**，`shape=[9000, 2]` |
| M1 选中的那列是否**恰好等于** `:101` 的标签 | **True**（逐元素相等） |
| M2 真 `run_aux_tcn(feature_cols=["ret5"])` | `COMPLETE_AUX` |
| M2 真 `run_aux_tcn(feature_cols=["ret5","aux_ret1"])` | **`COMPLETE_AUX`**，`representation_features=2` |
| 对照 `_forbidden('label_joint')` | `True` → `FeatureSpecError`（**同类问题的 H504 侧被拦，AUX 侧不拦**） |

**机制**：目标是**同一列**的确定性函数（正负号），把它放进输入等于把答案的一个 1-bit 投影直接交给模型。而该路径没有门，所以不会报错，只会 `COMPLETE_AUX`。

**影响（严格定级）**
- **契约违反而非精度断言**：我证明了"标签可作输入且系统接受"，**没有**证明历史上真的这么跑过；`magnitude` **未计数**。D 在 1 epoch / 8 股 smoke 上量到相对因果基线仅 ~2.4e-4 logloss，属噪声量级，故**不主张**它抬高了任何成绩。
- **默认路径不可达（实测）**：`--stage aux-tcn` 传的是 `_feature_cols(build_research_features(panel))`，实测 `n_feature_cols=61`，`aux_ret1` **不在其中**（`aux_ret1_in_default_fc = False`）。`aux_ret1` 只出现在 `aux_tcn.py`（全仓库产品源码 6 处，全在该文件），feature builder 不产出它。
- 因此定级为 **latent / 调用方署名可达**，**不是**默认泄漏。

**修复建议**：在 `:94` 的选择之后追加"所选列 ∩ 目标列（`aux_ret1`/`aux_rv5`）必须为空"的硬断言；仅靠黑名单不行（`aux_ret1` 这种名字没有前缀可归类）。

**验收测试**：`feature_cols` 含 `aux_ret1` **必须**失败（当前实测 `COMPLETE_AUX`，即负向臂已具备）；不含它时**必须**仍成功（正向臂）。
