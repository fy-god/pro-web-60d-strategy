`data/cards_100/scores.json` 记录：

- `sample_count = 100`

- `rsi_mean_reversion.predicted_yes_rate = 0.0`
- `rsi_mean_reversion.tp = 0`
- `rsi_mean_reversion.fn = 50`

- `rsi_mean_reversion.accuracy = 0.5`

同一文件中，RSI 专家与 `accumulation_base`、`first_board_breakout`、`high_level_consensus`、`turnover_weak_to_strong` 的 pairwise disagreement 为 0，而这些策略本身在该归档也没有正预测。与 `bollinger_squeeze` 的 disagreement 为 0.62、与 `relative_strength_rank` 为 0.45、与 `obv_volume_price` 为 0.64，恰好等于这些策略各自的正预测比例——这与“RSI 专家始终预测 0”完全一致。

### 2.1 如何解释

这不是 H504 证据，也不是自然市场基率。`cards_100` 是一个 100 样本、50/50 正负的练习归档，`outcomes.json` 中是 10 个后续 bar 的事件；它只能作为**真实卡片级机制 sanity benchmark**。

但这个归档已经足够否定一种工作方式：

> 继续把 `rsi_mean_reversion` 的 0/1 决策作为“RSI 已参与 ensemble”的充分证据。

当前策略公式是：

```text
0.30 * RSI超卖
+0.25 * drawdown
+0.20 * rejection
+0.15 * KDJ turn
+0.10 * nonpanic volume
threshold = 0.68
```

在该真实归档上它一次都不触发，说明这个阈值化复合专家对这 100 个样本没有任何发布覆盖。它的原始连续 score 或 RSI 子分量**仍可能含有排序信息**，但现有 `scores.json` 只保存汇总，不足以判断。

### 2.2 新研究 ID

`EML-RSCH-RSI-BINARY-DEAD-CARDS100`：**研究发现，不作为 P0/P1 代码 bug。**

- 现象：100-card 真实归档上二进制 RSI 专家零激活。
- 影响：该归档上的 ensemble 多样性中，RSI 规则没有实际正票贡献；不能用“策略文件存在”推导“RSI 已经被有效融合”。
- 下一步：从同一 card 顺序重新导出 `RSI14`、原始 score、五个 component 和新的 fresh/roll-out/RER 分量，先做不调阈值的连续排序诊断。

## 3. 本轮因子改造：从单一 RER 改成可归因的 RSI-Recovery Vector

上一轮 RER 的核心思想保留：区分“今天／近期新进入窗口的价格变化”与“旧变化滚出窗口”。独立复核已确认反例和数学分解，但也正确指出 `N+E=ΔRSI` 是构造性恒等式，不应计为预测验证。

所以本轮不再把“恒等式通过次数”当研究成果，改为验证**可失败的预测命题**。

建议新增的连续特征向量：

```text
rsi_sma14
rsi_delta_1
rsi_delta_3
rsi_new_1
rsi_rollout_1
rsi_new_3
rsi_rollout_3
rsi_positive_new_3 = max(rsi_new_3, 0)
rsi_positive_rollout_share_3
support_break_log
support_break_atr
rsi_effective_recovery
```

其中：

```text
positive_new = max(N3, 0)
positive_roll = max(E3, 0)
rollout_share = positive_roll / (positive_new + positive_roll + eps)
```

`rollout_share` 只在 `ΔRSI3 > 0` 时解释为“表面恢复中有多少正向变化来自旧项滚出”；其余情况保留 raw 或 missing，不硬赋 0/1 语义。

### 3.1 为什么把价格支撑惩罚改成 ATR 归一化

上一版 RER 对最近低点破坏用了固定对数尺度 `0.03`。这能作首轮候选，但同样 3% 的破底对于低波动与高波动股票含义不同。

本轮增加：

```text
support_break_abs = max(0, L_pre - L_now)
support_break_atr = support_break_abs / (ATR14 + eps)
```

然后让模型同时看 `support_break_log` 与 `support_break_atr`；若要保留一个交互分数，候选为：

```text
RER_ATR = tanh(max(N3,0) / 5) * exp(-support_break_atr)
```

这不是替换 raw 分量，而是一个额外的低容量交互。**不允许只保留 RER_ATR、删掉 N/E/价格破坏原始量后再宣称 RSI 有效。**

### 3.2 与 KDJ 的融合方式

不建立第二个“RSI专家投票”，优先进入同一个连续特征矩阵：

```text
B                         基础价量/长期位置/市场背景
B + KDJ                   KDJ增量
B + RSI-state             RSI水位与变化
B + KDJ + RSI-state       RSI|KDJ条件增量
+ fresh/rollout vector    是否需要滚出分解
+ RER_ATR                 是否需要显式交互
```

KDJ 与 RSI 都来自价格，不能把它们包装成两个独立外部信息源。真正问题是：**控制已有收益率、位置、KDJ和相同历史长度后，RSI表达是否使有限容量模型更容易排序 H504 联合事件。**
