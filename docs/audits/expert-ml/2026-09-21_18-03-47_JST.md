## 3. 新研究分析：20.84% RF 的优势是否只是一个小折偶然抬高？

实验 ID：`EML-ARCH-H10-FOLD-SUPPORT-01`

证据只来自已归档 `reports/ml_search_models.json`，属于 **H10 / High +30% / 开发期**，不是 H504，也不是本轮重训。

### 3.1 RF 的四折支持

`fam_rf_5`：

- pooled signals = 22,867
- pooled precision = **20.8379%**
- 四折 precision = **22.8814% / 18.3571% / 18.0583% / 20.7135%**
- 四折 signals = **11,210 / 7,365 / 1,545 / 2,747**
- 四折相对各自 base lift = **7.64x / 2.29x / 6.83x / 7.26x**
- 最低折 precision = **18.06%**
- precision CV = **11.28%**
- 最大单折信号占比 = **49.02%**
- signal-share HHI = 0.3631，对应 **2.75 个有效支持折**
- 4/4 折均高于各自自然基率

因此 20.84% 并不是靠最后一个 200–300 信号的小折把 pooled 值抬起来；它的最低折仍在 18% 左右，且信号分布比 HGB 候选均衡。

### 3.2 HGB 的 pooled 数字有更强的单折集中

| config | pooled precision | signals | 最大单折信号占比 | 有效支持折数 | 最低折precision |
|---|---:|---:|---:|---:|---:|
| `fam_hgb_1` | 17.18% | 15,389 | **85.88%** | **1.34** | 16.02% |
| `fam_hgb_2` | 16.57% | 12,179 | **80.31%** | **1.49** | 14.74% |
| `fam_hgb_0` | 16.44% | 12,143 | **83.78%** | **1.39** | 14.56% |

HGB 的高折 precision（约 33%–34%）分别只对应 359 / 253 / 375 个信号，而 pooled 支持主要来自第一折。这不说明 HGB 无效——4/4 折仍高于各自 base——但说明只看 pooled precision 会掩盖**支持分布极不均匀**。

### 3.3 ExtraTrees 是一个有价值的“稳定性控制”

`fam_extratrees_6` pooled precision 只有 15.53%，不如 RF；但四折 signals 为 6,959 / 6,471 / 4,928 / 5,253，最大折仅 29.47%，有效支持折数 **3.92**。它适合作为“如果更均衡的发布覆盖换来更低 precision，RF 的优势是否仍成立”的对照。

### 3.4 负控制仍支持“不是明显的随机管线幻觉”

`reports/ml_null_tests.json`：

- permuted labels：mean precision = **3.1067%**，mean base = **3.0842%**；
- noise features：precision = **4.0628%**，base = **4.0894%**，lift = **0.9935x**。

这支持“RF 20.84% 不是由一个连随机/噪声都能得到巨大 lift 的明显坏管线直接造成”的判断；它**不证明**所有泄漏路径已排除，更不把开发搜索变成最终无偏证据。

### 3.5 研究决策

对 H10：如果未来有一个真正未被模型/阈值选择使用的新时间块，优先冻结 `fam_rf_5` 做一次评价；同时带上 `fam_extratrees_6` 作为覆盖稳定性控制。不要继续在已曝光开发折上为了超过20.84%无限模型家族搜索。

对 H504：只继承“模型候选优先级”的思想，不继承阈值、精确率或特征淘汰方向。H504仍必须在自己的 TaskSpec、candidate ledger、market-session clock 和成熟时间折上重新训练评价。

直接做 RF vs HGB 的普通二项 z-test/Wilson 差异检验在这里不合格：两模型处于相同时间折、预测样本重叠且模型家族本身已被开发搜索。没有逐候选配对预测就不能把“区间不重叠”包装成模型显著性。
