### EML-P1-DOWNVOL-EMPTY｜未修，本轮新发现

**定位：**`src/lowzone.py::build_layers`。


## 3. 一套主改造：统一时间与发布契约，增加可检验的低位量价机制

### 3.1 目标、非目标与三层基准

目标是先使候选总体、标签可知时间、发布与结果记录一致，再检验“低位KDJ状态＋供需量压力”是否减少假反弹误报。不靠提高阈值减少到几条信号来冒充信息增量。

非目标：不恢复旧100张卡70%叙事，不把H10研究改名为H504，不立刻上大型深网，不删除KDJ／位置，不重新定义财富收益目标。

冻结三个互不替代的基准：

| ID | 内容 | 允许如何比较 |
|---|---|---|
| B0-legacy | 固定SHA当前H10/High源码及归档 | 仅复现与确认程序变化，不叫新成绩 |
| B1-H10-causal | 同H10目标，修正时间、候选、发布和汇总 | 修复导致的变化单列，不归因于新模型 |
| B2-H504-closejoint | 新建用户指定H504/Close/Low联合任务，保留KDJ与位置 | 所有新模型、机制和消融只在该TaskSpec内部同条件对照 |

这三层必须分别输出结果；B0到B1是程序与评估修复，B1到B2是任务变化，B2内才讨论模型信息增量。

### 3.2 TaskSpec与数据schema

```yaml

universe: A_share_PIT
signal_asof: market_session_close
entry_offset_market_sessions: 1
entry_price_field: open

horizon_includes_entry_session: true

goal_multiple: 4.0
risk_price_field: low
risk_operator: lt

tie_priority: risk

adjustment_asof: REQUIRED_IF_ADJUSTED
wealth_return_is_target: false

```

用户没有固定具体复权基准，本方案不擅自选用一条跨公司行动不一致的原始或复权价格路径。旧任务保留其数据口径并标未知元数据；新H504要求明确配置。价格序列统一尺度的E、Close、Low属于同一price_basis；wealth NAV另表，不能据财富4倍算价格4倍。

四张关键表，所有ID和时间使用可比的市场session及明确时区：

```text

  task_id, candidate_id, code, decision_session, decision_asof,
  eligibility_asof, feature_asof, feature_schema_hash, universe_hash

```

### 3.3 标签时序、删失与训练可知性

令t为决策市场日，E为t+1市场日开盘代理价。对j=1,...,504逐日：

```text
已知Low[j] < 0.8E  -> 风险终止
否则，已知Close[j] > 4E且此前安全路径可验证 -> 成功终止
否则，继续观察
走到期限而未达标且观察完整 -> 超时负例
入场或中间观察不可判定 -> 单独unknown/censored，不填成负例
```

缺失区间后的Low或Close不能倒推出缺失区间安全。已知停牌与采集缺失分别处理。`known_at`是相关结果进入历史可用数据库的时间，不只是一张未来完整表上的resolved标志。

第一版保守二分类训练只用完整deadline已到且资料齐全的候选，统一要求`label_end < fit_asof`且`known_at < fit_asof`；即便某正例提前成功，也不在基线中单独提前吸收它，以免正例早可知、负例晚可知造成选择偏差。提前终止样本的利用可另做删失／竞争风险实验，不能混入同名基线。

仓库自述约887市场日、2023年至2026年的快照。在H504及较长特征预热、训练、独立校准和外层测试共同约束下，可用分割非常有限。实施前先输出time_budget.json；不能简单把原H10四折参数改为504强行训练，也不能改回High或缩短期限来凑样本。必要时补充更长、来源可核验的历史数据；数据未齐时只完成契约与离线测试。

### 3.4 原始专家分量与家族去重

当前独立ML已经有82个连续特征，包含KDJ和位置，不应把“加入原始KDJ”包装成全仓库首创。新增价值在于把逐时点状态、持续性与真实量价机制显式输出。

建议同一候选同时保留`raw_value`、`quality_score`、`validity`、`missing_reason`、`family_id`和`score_definition_hash`。改造runner不再只保留prediction/score而丢弃分量。对同一分数不同阈值的strict变体，只有一个原始专家维度；它们的阈值是policy候选，不是多票支持。

对浅回踩采用有边界的分段质量，例如-8%以下随更深跌幅降至0，而不是继续得1；破坏支撑的标志单列门控。对缺口采用先增、平台、再下降的质量形状。具体拐点只在开发段选择，保存旧分数供兼容对照。

### 3.5 修复量压力，并构造难负例

保留D_w=过去w个有效市场日下跌日成交量总和，U_w=上涨日成交量总和，及各类天数。平盘单列，缺失不当零。定义：

`pressure_w = (D_w - U_w) / (D_w + U_w)`，仅当分母>0且覆盖足够时计算。

该量正值表示成交量偏向下跌日，不解释为直接资金流入流出。另存下跌日均量／上涨日均量、up_count/down_count、zero_side与missing标记；只做有统计语义的零分母处理。单侧全上涨或下跌的有界压力可为-1或+1，但均量比不应伪造。

训练负例按当前TaskSpec分成：先破0.8E；完整期限未达标；High超过4E但Close未达标；看似低位金叉后再次破坏结构。所有类别只能在训练as-of已可知时用来抽样。未知不是第五类负例。

损失先用未加类别权重的二元交叉熵。若为节省拟合成本对负例分层抽样，样本被抽概率q_i必须保存，用w_i=1/q_i校正训练；不改变校准／测试自然总体。重叠事件唯一性权重作为独立备选实验，不默认叠加一堆权重。加权输出不得直接命名真实概率。

现有competitive的`loss=1-joint`包含未达标和破位，不是单独“破位概率”。后续风险头要么明确预测risk-first，要么直接预测joint；不能拿旧loss分数充当已校准风险概率。

### 3.6 真正时间外的元学习、校准和发布

1. 基础模型按扩展时间窗产生OOF分数；每行记录max_train_label_end／known_at均早于自身预测as-of。编码、缺失处理、特征选择也只能拟合该行之前的数据。
2. 元模型只能使用这种OOF分数与当时特征，不能使用同批训练上的s_tr。正则logistic作为起始meta；样本不足则回退单模型，不能回填in-sample scores。
3. 与选型分离的校准段拟合概率映射，校准段保持自然基率、不使用难负例重采样。保存Brier、log-loss、分箱可靠性和校准斜率。当前训练分数top2%只叫发布阈值，不叫概率校准。
4. 校准概率与发布policy分别冻结。初始policy沿用基准的先验发布预算，固定冷却60个市场日，固定并列code顺序；测试期不反向调阈值匹配更好命中率。在线同日Top-K是合法备选政策，但不能和冻结绝对阈值混为一张增益表。
5. 决策账本先冻结再接label；两周查询只读账本。执行受阻不能擦掉发布事实或替补为事后更好的股票。

起始资源与超参：一个保留KDJ/位置的HGB基线，沿当前HGB配置leaf15、minleaf300、L2=10、learning_rate=.03、300轮、关闭自动early_stopping；meta logistic C=0.1；种子0/17/101；本地workers<=2、单任务线程1。先做数据时间可行性与不超过20万训练行的加权抽样开发烟雾测试；评估候选保持完整日截面。资源上限是待实施配置，不是本轮已经训练。

## 5. 优先研究实验与两个备选

### X17-KDJ-PRESSURE-PATH｜优先；待验证假设

**依据：**本轮发现`down_vol_ratio5`没有提供信息；现有独立ML已有KDJ、位置、短期动量和一般量比，不能声称仅添加这些点值就是新信息。真正待测试的是：相似低位KDJ状态下，卖出日量压力是否衰减、底部是否多次稳住、反弹是否反复失败，能否区分健康转折与下跌中继。

**与已计划实验区别：**X13–X16是目标／时钟／账本修复，不是这个模型假设；本实验也不是已有“删除cross”“统一加权”或更换模型名称。它输出具体过去路径变量，并把down_vol原列修复单独作为一行对照。

**新增输入起始定义：**

- `kdj_low_occupancy20 = mean(K<30 & D<30)`，窗口20个有效历史观察，另报20市场日覆盖率；KDJ源递推保留连续历史。
- `cross_age`：最近一次K上穿D以来经过的市场日数，未发生则单独标志，不伪造0。
- `pressure5/pressure20`及`pressure_relief = pressure20-pressure5`；正值只解释为近期成交量较少偏向下跌日。
- `floor_retest_count`、`failed_rebound_count`：采用仅向后看的固定窗口算法，不能用未来确认的zigzag低点；拐点及恢复门槛开发前锁定。
- `lowzone_dwell`：过去20/60市场日中落在规定历史价格位置区域的占比，保留缺bar覆盖率。

**数据与成本：**需WP1–6通过、实际H504成熟标签和足够历史。优先复用冻结基础特征缓存，只新增路径列；开发烟雾测试训练最多20万行、完整候选评价、2workers、3seeds。扩大前先检查实际内存和可用折，不启动远程训练；本轮无此市场数据，未执行该实验。

**预注册主要判据：**同TaskSpec、候选、时间块及冻结发布政策下，比较paired的TP、precision、event recall与信号覆盖；重点查看risk-first误报，而非在最终测试选最高precision阈值。开发段预设最低信号量／股票量／有效日期块，样本不足不晋级。

**淘汰：**只在一只股票／一个日期簇有效，或与充分raw特征基准配对差值不稳定；所谓提升完全来自少发信号／删未知；去掉未来pivot后收益消失；数据不足以区分真假增益。方向在开发阶段不成立就记录无支持，不继续搜阈值救结果。最终外层测试只验证已冻结选择，不决定换方向。

对照raw连续特征、旧clip、修复后的质量映射，以及质量映射＋因果失效门控。主要回答R09中的饱和误报是否能减少。风险是门控压掉长期大牛股早期信号；event recall若明显下降，不以precision上升掩盖。该方向是语义修复后的模型效果验证，不自称已经可靠。
