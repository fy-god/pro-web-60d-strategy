### 2.5 新增：`AUC≈0.5 ⇒ RSI 无用` 不可判定，因为该项被**截断**

**文件/行**：`experts/strategies/rsi_mean_reversion.py:46`

```python
45  rsi = relative_strength_index(card.bars, 14)
46  rsi_oversold = _clip((45.0 - rsi) / 20.0)      # rsi14 > 45 -> 恰好 0
```

实测 `rsi14` 的真实分布：

```text
n=100  min=42.22  max=100.00  mean=67.38
rsi14 >  45 (=0，完全截断)  : 97/100
rsi14 <= 45 (非截断)        : 3/100   -> 值 42.54 / 42.22 / 42.81，label 全为 0
rsi14 <= 25 (满分)          : 0/100
```

**机制/影响**：`_clip` 把 97% 的卡片**在进入 AUC 之前**就压成同一个值 0。于是 `AUC(rsi_oversold) = 0.4700` 这个数**几乎不含 RSI 的信息**——它主要由 3 张非截断卡贡献，而 `0.4700 = (2500−150)/2500` 正好说明「它只是那 150 个配对的产物」。这 3 张卡全为负例，在随机标签下 `P(3 张全负) = C(47,3)/C(50,3) = 0.827`——**毫无信息量**。

**因此该报告 L21/L113 的推论方向虽不错，但其「AUC≈0.5 说明 RSI 分量没有信号」的**推理链**不可判定**：数据同时兼容（a）RSI 确实无信息，与（b）RSI 有信息但被 `_clip` 的硬阈值遮蔽。要区分二者，必须先**解除截断**（用原始 `rsi14` 或分段/更宽窗口），再测。

**修复建议（程序修复）**：该审计报告的验收清单（其 §2.3，要求 `cards100_rsi_attribution.csv` 逐卡含 `rsi14` 与 `score_rsi_component`）**方向正确**——它恰好能暴露截断。建议在其上**强制加一列 `rsi14` 原值**并报告 `非截断卡数`、`截断率`、以及 `AUC(rsi14_raw)`。**验收测试**：断言 `cards100_rsi_attribution.csv` 中 `rsi14` 存在且 `截断率` 被显式打印；若 `rsi14` 被丢弃或仅存 `rsi_oversold`，该实验**不得**被引用为 RSI 结论。
