## 0. 结论与本轮交付

提出并实现一个新候选：**ARR，冻结锚点的恢复—承接因子**。它在一次可知的KDJ回踩开始时冻结支撑位、ATR尺度与起点收盘，随后同时观察RSI新增恢复、Wilder恢复、实际价格响应和累计低点破坏。目的不是把“RSI低”变成买点，而是避免用不断变化的支撑/分母把同一次破位重新描述为改善。

这是一项明确的研究假设，不是已验证选股规律。冻结支撑可能过时，也可能错过有价值的恐慌后反转。因此原始分量和滚动版本都保留，交互分数不作硬门槛、不作概率。

本轮不只写方案：完成独立可运行候选包、真实CSV流式适配器、标签oracle、因子实现、神经网络训练器和测试。最终49项pytest通过；4种有意变异全部被红测抓住；处理1,048,576行合成OHLCV；完成6组HGB、3组MLP、3组TCN的拟合/选择/保存/重载/全候选预测。**百万行是合成压力数据；训练也是合成H504。没有真实市场成绩。**

补上相同参数量、相同缺失mask的零ARR对照后，两个神经网络的ARR版本都未改善log-loss/Brier。HGB的ARR列没有被任何分裂节点使用。保留这个负结果，不通过继续扫阈值制造收益。

## 2. ARR机制、公式与边界

### 2.1 冻结一个可知的回踩episode

在独立市场日历上，前一天K>=30、当天K<30且D<50时触发tau；必须有至少60个**连续有效OHLC市场日**。这是研究起始阈值，不是最优参数。

触发时冻结：

S_tau = min(Low[tau-20:tau-1])

A_tau = ATR14[tau-1]

C_tau = Close[tau]

ATR14采用14个真实范围的算术均值，版本显式命名；A_tau<=0则不启动。episode持续21个市场日，期间不因再次金叉/跌入阈值而重新锚定；未知价格缺口终止当前状态并标unknown，只有重新满足完整预热和新触发才再启动。仅volume缺失不抹掉价格状态。

累计损伤与价格响应：

B_t = max(0, (S_tau - min(Low[tau:t])) / A_tau)

R_t = (Close_t - C_tau) / A_tau

B_t在同一episode内非递减。它不会因为旧低点离开滚动窗口或当前ATR增大而自行下降。R_t保留正负：指标恢复但股价仍低于回踩起点时，价格响应不是正向承接。

该技术支撑不是label中的0.8E。决策时没有未来entry E，E及未来合同字段不进入特征。

### 2.2 RSI恢复保留原始分量

令gain=max(deltaClose,0)，loss=max(-deltaClose,0)，F(U,D)=100U/(U+D)。SMA窗口滚动前U/D，新增gain/loss为u/v，移出旧值为a/b。四状态：R00=F(U,D)，R10=F(U+u,D+v)，R01=F(U-a,D-b)，R11=F(U+u-a,D+v-b)。

incoming = [(R10-R00)+(R11-R01)]/2

rollout = [(R01-R00)+(R11-R10)]/2

incoming+rollout=deltaRSI。三日incoming累计记F3，W3为Wilder14的三日变化。SMA和Wilder使用明确不同版本；Wilder以首14个有效价差均值初始化，递推alpha=1/14，缺口后重新预热，不能隐性跨缺口续接。

M_t = sqrt(tanh(max(F3,0)/5) * tanh(max(W3,0)/5))

**ARR_t = M_t * exp(-B_t) * tanh(R_t)**

5表示5个RSI点的起始尺度。ARR属于[-1,1]，不是概率；无episode时NaN+mask，不删除候选。持续强势RSI=100但没有“新恢复”时，ARR可能0，不等于看空。禁止ARR<=0全局禁买或RSI>70排除。

保留RSI水位/变化/incoming、rolling RRC、固定B/R、episode active/age、已完成episode损伤和ARR，不能只给模型一个乘积分数。对照共享active/age，避免把新增候选资格或缺失覆盖误称因子价值。

### 2.3 独立机制反例

同一次回踩里，初始支撑100、ATR2，低点97；后续低点仍97，但滚动支撑下降到97、ATR升5。

|时点|Low|滚动惩罚|冻结惩罚|
|---|---:|---:|---:|
|2|97|1.5|1.5|
|12|97|0|1.5|

动态版本看似“不再破位”，固定版本仍记得同一episode已经破坏1.5ATR。这里没有声称未来收益发生变化。

最初实现仅判断全局日历位置>=60，不能确保该股票/缺口后有60日真实历史。独立短历史测试抓住后，改为连续有效价格计数，版本arr-1.0.1。百万行样本active由414,717变为411,211，差-3,506。旧9次fit保留为superseded，不与修正后12次模型挑赢家。
