### 2.1 `H504TaskSpec` 与标签oracle

`label_h504_candidates(panel, candidates, spec, calendar)` 以**独立市场日历**处理：

- t日收盘后候选；
- 仅下一市场日有有效Open才得到E；缺t+1 bar/无效Open = `no_entry`，后续复牌不补入；
- deadline = t + 504 market sessions；
- 从entry session起逐市场日扫描，先判断 `Low < 0.8E`，再判断 `Close > 4E`，因此同日risk优先；
- `Close == 4E` 不成功；
- 完整504日无事件 = `timeout`，标签0；
- 未来日历不足 = `pending_maturity`；
- post-entry缺bar/缺价格在候选实现里保守标 `unknown_missing_bar/price`，不静默连接到后续复牌；生产接入前必须增加“确认停牌 / 数据丢失 / 退市”的独立状态适配器，不能直接把这一保守规则当最终市场语义。

输出字段包括：`candidate_id/code/signal_date/entry_session/deadline/entry_open/target_price/risk_floor/terminal_session/label_known_at/training_eligible_at/outcome_class/label_joint/label_resolved/bars_scanned/first_missing_session`。

这里将 `training_eligible_at=deadline`，即使成功或risk早发生，也不让完整随访BCE因为早终止而吸纳更近期的样本；这与“固定成熟日期队列”要求一致。

### 2.2 `FeatureSpec` 改成fail-closed白名单

候选 `FeatureSpec.from_names([...])` 要求显式列出训练特征。新metadata即使出现在DataFrame中，也不会被自动加入模型；`known_at/deadline/label_*/forward_*/outcome_*/execution_*/publication_*` 等合同列若被显式列入则直接抛错。

这不是对现有 `META_COLUMNS` 再加十几个名字，而是把方向从“默认允许”改为“默认拒绝”。

### 2.3 `fold_support` 把887日矛盾做成机器检查

`enumerate_mature_splits()` 同时要求：

- 训练候选的 `signal_index + 504 < dev_start_index`；
- dev候选本身的 `signal_index + 504 <= last_calendar_index`。

实际单元测试：887个market sessions、候选覆盖全部session、H=504时合法成熟train→更晚成熟dev split数量 = **0**；1200个session的合成日历则能找到合法split。这个模块用于生成本地 `fold_support.json` 的核心判定，而不是凭文字说“数据可能不够”。

### 2.4 VIR首次落成可测试实现

`volume_impact_recovery()` 实现先前预登记的VIR：

- `r_s=log(C_s/C_{s-1})`；
- 价格尺度用 `ATR14_{s-1}/C_{s-1}`，只依赖此前信息；
- relative volume分母用当前日之前20行均量；
- 比较 `[t-19,t-10]` 与 `[t-9,t]` 两个不重叠10-session块的上涨/下跌单位相对成交量冲击；
- 同时输出price-only `vir_novol`、recent/prior上下行impact、上下行计数、coverage和one-sided，而不是只留一个合成分数。

本轮额外修正了一个容易漏掉的gap检查：不能只用“20行首尾session_id差=19”判断连续，因为“重复一个session + 跳过一个session”端点跨度仍可能等于19。实现改为要求窗口内**每一条相邻session_id差都严格等于1**；专门加入“duplicate + compensating jump”测试。

### 2.5 专家家族冻结ECDF

`FrozenFamilyECDF` 只在train block拟合每个去重机制家族的经验CDF；开发/测试只transform，不重新拟合。输出 `family_q__*`、`meb`、`family_coverage`、75/90支持数与`family_dominance`。strict threshold clone不应该以独立family列进入这里。
